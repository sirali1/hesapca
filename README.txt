HESAPÇA - APK OLUSTURMA

Yol 1: Android Studio
1. Android Studio'yu ac: File > Open > bu klasoru sec. Gradle senkronu bitsin.
2. Build > Build APK(s). APK: app/build/outputs/apk/debug/app-debug.apk
3. APK'yi telefona gonder ve ac (bilinmeyen kaynaklardan yuklemeye izin ver).
   Ya da telefonu USB ile baglayip Run dugmesine bas.

Yol 2: Android Studio olmadan
1. Bu klasoru bir GitHub deposuna yukle.
2. Actions sekmesinde "APK derle" calisir; bitince "Hesapca-APK" dosyasini indir.

Uygulama icerigi: app/src/main/assets/hesapca.html
